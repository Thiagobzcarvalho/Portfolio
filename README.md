# Portfólio Pessoal — Thiago Braz

Portfólio pessoal estático desenvolvido como meu primeiro projeto de
desenvolvimento web, com o objetivo de apresentar minha trajetória acadêmica,
conhecimentos atuais e objetivo profissional.

O projeto representa meu momento atual de aprendizado e continuará sendo
evoluído conforme eu adquirir novos conhecimentos.

## Objetivo

Apresentar minha formação em Ciência da Computação, meus conhecimentos,
objetivos profissionais e minha evolução na área de tecnologia.

O site é tratado como um projeto em desenvolvimento, atualmente na versão
`v0.1.0`.

## Tecnologias utilizadas

- **HTML5** — estrutura e organização semântica da página.
- **CSS3** — estilização, responsividade e interações visuais.

O projeto não utiliza JavaScript, frameworks, bibliotecas ou dependências
externas.

## Interações com CSS

Algumas interações que normalmente poderiam utilizar JavaScript foram
desenvolvidas utilizando recursos nativos de HTML e CSS.

### Menu mobile

O menu mobile utiliza um `input` do tipo `checkbox` associado a um `label`,
permitindo abrir e fechar o menu sem JavaScript.

### Navegação entre seções

A navegação utiliza âncoras HTML e recursos de CSS como `:target` e `:has()`
para auxiliar no destaque da seção atual.
